💡 Come ricevere gli ordini e i file STL anche via Email o WhatsApp:

Poiché GitHub Pages è un hosting statico gratuito, oltre a vederli in questa Dashboard puoi ricevere i file dei clienti direttamente sui tuoi canali preferiti:

  1. Ricevere i file direttamente nella tua EMAIL (Consigliato): Utilizza un servizio gratuito come Formspree (50 sottomissioni/mese gratuite) o Web3Forms. Ti basta inserire il tuo codice endpoint nell'azione del form in index.html e riceverai un'email per ogni nuovo preventivo con i file STL/PDF allegati.
  2. Ricevere i file su WHATSAPP: Il pulsante "Invia su WhatsApp" integrato apre istantaneamente la chat diretta con il tuo numero di telefono precompilando il riassunto dell'ordine (materiale, 4 colori scelti, prezzo calcolato).
  3. Caricamento su Google Drive: I file STL superiori a 20MB possono essere collegati al tuo Google Drive o WeTransfer semplicemente aggiungendo il link nelle note del cliente.
