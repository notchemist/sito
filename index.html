Domande Frequenti

Puoi inviarci:
1) Un file .3MF già colorato (es. esportato da Bambu Studio, PrusaSlicer o OrcaSlicer).
2) Un file STL composto da corpi solidi separati per ogni colore.
3) Un file STL monoblocco accompagnato dal nostro PDF di istruzioni in cui indichi: "Scritte in Arancio, Corpo in Nero, Dettagli in Ciano". Ci occuperemo noi della colorazione nello slicer!
